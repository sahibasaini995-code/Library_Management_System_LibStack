# 📚 Library Management System - LibStack

LibStack is a web-based Library Management System designed to make library operations simple, organized, and user-friendly.

The application provides a frontend interface for managing library activities and a Spring Boot backend for handling application logic and APIs.

---

## ✨ Features

- 📚 Library book management
- 👨‍🎓 Student/member management
- 🔄 Issue and return book management
- 📅 Date-based library operations
- 🔍 Easy-to-use user interface
- 🌐 REST API based backend
- ⚡ React + Vite frontend
- ☕ Spring Boot backend
- 📱 Responsive web interface

📌 Main Modules
📚 Book Management

The system provides functionality related to managing library books and their availability.

👨‍🎓 Student / Member Management

Library members can be managed through the application.

🔄 Issue & Return

The application supports library book issue and return operations.

📅 Date Management

Dates can be selected and managed for library-related operations.

🧪 Development

For backend development:
cd backend
mvn spring-boot:run

For frontend development:
cd client
npm install
npm run dev
