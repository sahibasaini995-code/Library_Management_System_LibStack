# 💼 Job Portal

A full-stack web application that connects job seekers with employers through an easy-to-use online platform.

The Job Portal allows users to explore job opportunities, manage job applications, and provides employers with functionality to manage job postings and candidates.

---

## 📌 Project Overview

Finding and managing job opportunities can be difficult when the process is handled manually.

This Job Portal provides a centralized platform where:

- 👨‍💻 Job seekers can explore available jobs
- 🔎 Users can search for suitable job opportunities
- 📝 Job seekers can apply for jobs
- 🏢 Employers can manage job postings
- 📋 Employers can manage applications and candidates

The project was developed as a collaborative full-stack application.

---

## ✨ Key Features

### 👨‍💻 Job Seeker

- User registration and login
- Browse available job opportunities
- Search and explore jobs
- View job details
- Apply for jobs
- Manage profile information
- Track job applications

### 🏢 Employer

- Employer registration and login
- Create job postings
- Manage posted jobs
- View job applications
- Manage candidate information

### 🔐 Authentication

- User authentication
- Secure login and registration
- Role-based access for different users

🚀 How to Run the Project


1. Clone the Repository
git clone https://github.com/YOUR-USERNAME/Job-Portal-Project.git
2. Backend Setup
cd backend
npm install
npm start
mvn spring-boot:run
3. Frontend Setup

Open another terminal:

cd frontend
npm install
npm start
npm run dev
🔐 Environment Variables

Create a .env file in the required project directory and add the required environment variables.

Example:

PORT=5000
MONGODB_URI=your_database_connection
JWT_SECRET=your_secret_key
